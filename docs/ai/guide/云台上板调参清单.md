# 云台上板调参清单（DM-J4310 双轴，infantry_dm_mc02）

> 对应 Decision-20261105-01 的第 6 步。参数在 `config/profiles/infantry_dm_mc02/params.hpp`，
> 调完写回那里；上板记录由负责人写到 `docs/records/<日期>_云台调参/`（测了什么、看到什么，原始日志放 `foray_mcu_archive`）。
> 工具：`tool/debug/gimbal_probe.py`（SWD 读云台的模式、目标、力矩、补偿力矩）、
> `tool/robolink/link_probe.py --follow`（实时 yaw/pitch/roll）。

## 0. 前提与安全

- 先按 `tool/flash/openocd/dm_mc02_cmsis_dap.cfg` 备份芯片 Flash（两次读一致才算数），再烧
  `build/arm-debug-infantry/firmware_infantry_dm_mc02.elf`。
- 两台 4310 接板上可控的 24 V 输出；`POWER_OUTPUTS{true}` 会在 `boot_init()` 里最先打开。
- **力矩上限先给小**：`GIMBAL.torque_limit_newton_meter = 1.0`（4310 峰值 12.5 N·m，夹到手指会很疼）。
- 云台周围别放东西；遥控拿在手上，拨杆随时能拨回。拨杆的"运行档"是出力的唯一来源：
  安全门锁住时 `Joint::available()` 为假，云台一直 DISABLED。
- 上电后约 40–70 s（加热到 50 ℃ + 零偏标定）IMU 才进 READY，之前云台是软的，这是设计。

## 1. 核对（不出力）

烧录后不碰拨杆，用 `gimbal_probe.py` 看：

| 看什么 | 应该是 |
|---|---|
| `gimbal.mode` | `DISABLED`，`last_disable_reason` 是"关节不可用"（安全门锁住）或"标定中" |
| `gimbal.yaw_available` / `pitch_available` | 都是 `True`（两台电机核对通过）；不是的话读 `g_dm_can_1` 快照的 `mismatch_register` |
| `gimbal.yaw_online` / `pitch_online` | 都是 `True` |
| `gimbal.yaw_fault` / `pitch_fault` | 都是 `False` |
| `gimbal.yaw_joint_rad`、`pitch_joint_rad` | 云台水平朝前时接近 0；差得多就回调试助手重设零点，或填 `zero_offset_rad` |

方向：用手把云台往左转，`yaw_joint_rad` 与 `yaw_rad` 应该**都变大**；把枪管往下压，`pitch_joint_rad` 与
`pitch_rad` 应该**都变大**。反号就把 `params::YAW_MECHANICS` / `PITCH_MECHANICS` 的 `direction` 改成 −1。
用手转得动（电机没有出力）。

## 2. 安全门与遥控

- 拨杆拨到运行档：`safety.state` 变 `1`（放开），`remote.running` 为 `True`，`arm_sequence` 加 1。
- 拨回：`safety.state` 回 `0`（锁住）。
- 关掉遥控器或拔接收机：超过 50 ms 后锁住，`safety.timeout_count` 加 1。
- 上电时拨杆就在运行档：`arm_sequence` 不变、安全门不放，要拨回去再拨上（故意的）。
- 拨杆通道与运行档的原始值不确定时，先用 bringup 固件读 `bringup.sbus` 的通道，拨一拨记下三档的值，
  再改 `params::REMOTE`。

## 3. pitch 的角速度环（先做，yaw 不出力）

`params.hpp` 里 yaw 的两组增益都是 0，云台只用 pitch 出力，yaw 用手扶着。

1. `GIMBAL.pitch.angle.kp = 0`（角度环输出恒为 0，角速度给定就是 0）。
2. `GIMBAL.pitch.rate.kp` 从 0.05 起，每次翻倍，直到出现嗡嗡声或抖动，再退回一半。
3. 加 `GIMBAL.pitch.rate.ki`，从 kp 的 5–10 倍起，消掉重力下垂；`rate.integral_limit` 先给 1.0 N·m。
4. 看 `gimbal.pitch_diagnostics.rate_target` 与 `pitch_torque_newton_meter`：推动枪管时力矩应该跟着反向、
   松手后回到 0 附近。

## 4. pitch 的角度环

1. `GIMBAL.pitch.angle.kp` 从 5 起往上加，到出现超调再退一点；`angle.output_limit` 先给 6 rad/s。
2. 用手把枪管拨开一点再松手：应该回位、不超调或只有一点超调，没有持续的嗡嗡声。
3. 高频嗡嗡声一般是角速度环 kp 太大或加了微分（本仓不加微分）。

## 5. 重力前馈

1. 云台水平静止，读 `gimbal.pitch_diagnostics.compensation_newton_meter` 的稳态值，那就是 τ_g。
2. 填进 `GIMBAL.pitch_gravity_newton_meter`，重新编译烧录，确认补偿力矩回到 0 附近
   （`pitch_gravity_newton_meter` 是水平时的重力矩，代码里按 `τ_g·cos(pitch)` 补）。

## 6. yaw

照第 3–5 步的顺序做 yaw：先角速度环、再角度环。yaw 没有重力前馈。
**误差回绕**：给一个跨 ±π 的目标（例如从 3.0 rad 转到 −3.0 rad），云台应该走近路，不绕一圈。

## 7. 扰动与验收

- 轻拍枪管：应该很快回位。
- 转底座：云台的指向应该基本不动（IMU 闭环的意义）。
- `runner[1]`：gimbal 任务每秒约 1000 轮、`overrun_count` 不涨、`max_run_us` 远小于 1000 µs。
- `dm.enable_failure_count` 与 `dm.request_timeout_count` 不涨。
- 拔掉 USB：云台照样稳住，急停照样有效（安全通路独立于上位机）。

## 8. 收尾

- 最后的参数写进 `params.hpp`，注释写清是怎么调出来的（改了哪个量、看到什么现象）。
- 力矩上限可以按机构强度逐步放宽，但**不要超过关节的 `maximum_torque_newton_meter()`**（J4310 为 10 N·m，
  峰值 12.5 N·m）：超过的话 `Gimbal::init()` 直接返回 false，固件启动失败。
- 把测点、现象与原始日志写进 `docs/records/`，并在 `decision.md` 的 Decision-20261105-01 补 Result。
