# 达妙电机寄存器回读的上板排查（2026-11-01）

负责人此前试过通过 CAN 回读达妙电机的寄存器（用来判断控制模式与量程），没有读出来。本次在 DM-MC02 上排查，结论：**能读出来**，
要点是应答发到电机的 MST_ID（默认 0x000），而不是请求用的 0x7FF 或 ESC_ID。

## 条件

| 项 | 值 |
|---|---|
| 电机 | DM-J4310-2EC V1.2（固件已由负责人升级到最新），接 DM-MC02 丝印 CAN1（FDCAN1），ESC_ID 1 |
| 供电 | 板上两路可控 24 V 输出，经 SWD 写 `GPIOC_BSRR = 0x6000` 打开（bringup 不打开它们） |
| 固件 | bringup `8d66a34`：不发 CAN，FDCAN1 的发送队列空闲，接收全部标准帧 |
| 方法 | 经 SWD 把请求帧直接写进 FDCAN1 的发送 FIFO 元素并置 `TXBAR`，再读接收 FIFO0 的消息 RAM（脚本见仓库外 `foray_mcu_archive/2026-11-01_dm_register_read/`）。只发读请求，电机不使能、不会动 |

## 结果

请求：标准帧 ID 0x7FF，4 字节 `01 00 33 RID`（ESC_ID 低字节、高字节、读操作码 0x33、寄存器地址）。每个请求都在 50 ms 内收到一帧应答：
**帧 ID 0x000**，8 字节 `01 00 33 RID` + 4 字节小端数据。

| 寄存器 | 应答数据 | 值 |
|---|---|---|
| 0x0A 控制模式 | `01 00 00 00` | 1 = MIT |
| 0x15 PMAX | `00 00 48 41` | 12.5 rad |
| 0x16 VMAX | `00 00 F0 41` | 30.0 rad/s |
| 0x17 TMAX | `00 00 20 41` | 10.0 N·m |
| 0x07 MST_ID | `00 00 00 00` | 0 |
| 0x08 ESC_ID | `01 00 00 00` | 1 |
| 0x0E 软件版本 | `37 30 32 30` | ASCII "7020" |
| 0x23 波特率代码 | `04 00 00 00` | 4 = 1 Mbps |

发送全部成功（`TXBTO` 逐位置 1），FDCAN1 收发错误计数始终为 0。

## 此前读不出的可能原因

1. 在 0x7FF 或 ESC_ID 上等应答：应答发到 **MST_ID**；MST_ID 默认是 0，应答的帧 ID 就是 0x000。
2. 应答与反馈帧共用 MST_ID，按反馈格式解析会把应答当成乱码丢掉。区分：应答的 D0–D1 等于 ESC_ID、D2 是操作码（0x33/0x55/0xAA）、D3 等于请求的寄存器地址。
3. 请求的 D0–D1 填了 MST_ID 而不是 ESC_ID。

## 对实现的影响

- 协议层 `protocol::DmEsc`（`src/driver/protocol/dm`）按上述格式编解码，宿主测试 `dm_protocol` 用这次的实测应答作样例。
- 驱动 `device::DmMotor`（2026-11-02，Decision-20261102-01）启动时回读控制模式与量程，与型号档案核对，一致才允许使能。寄存器应答按 D0–D1 等于 ESC_ID、D2 是操作码、D3 是核对用的寄存器来认；不在等待中的应答当作重复应答丢弃，不当成反馈。
- 建议给每台电机设不同的 MST_ID：同一总线上 MST_ID 都是 0 时，所有电机的反馈和应答都在 0x000 上，只能靠 D0 的低 4 位区分，ESC_ID 超过 15 就分不开。

## 补记：MST_ID 改为 0x11（2026-11-01 晚）

负责人在达妙调试助手（串口）里把这台电机的 Master ID 从 0x0 改为 **0x11**（约定 MST_ID = ESC_ID + 0x10，ESC_ID 0x02 的电机配 0x12；
前提是同一总线上的 ESC_ID 都小于 0x10）。改完用同样的方法经 SWD 注入读请求，固件为 bringup `0870a39`（上电已打开两路 24 V）。
应答全部改从 **帧 ID 0x011** 回来，其余参数不变：

| 寄存器 | 应答（帧 ID 0x011） | 值 |
|---|---|---|
| 0x07 MST_ID | `01 00 33 07 11 00 00 00` | 0x11 |
| 0x08 ESC_ID | `01 00 33 08 01 00 00 00` | 1 |
| 0x0A 控制模式 | `01 00 33 0A 01 00 00 00` | 1 = MIT |
| 0x15 PMAX | `01 00 33 15 00 00 48 41` | 12.5 rad |
| 0x16 VMAX | `01 00 33 16 00 00 F0 41` | 30.0 rad/s |
| 0x17 TMAX | `01 00 33 17 00 00 20 41` | 10.0 N·m |
| 0x0E 软件版本 | `01 00 33 0E 37 30 32 30` | ASCII "7020" |
| 0x24 子版本 | `01 00 33 24 30 30 30 31` | ASCII "0001" |
| 0x25 Boot 版本 | `01 00 33 25 03 02 00 06` | 原始字节，说明书没写怎么解读 |

这次回读的原始输出只留在当时会话的临时目录里，没有存进 `foray_mcu_archive`；上表的帧摘自当时的输出。
