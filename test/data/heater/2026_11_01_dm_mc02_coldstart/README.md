`a2cfd16_pi.csv` 也是辨识热模型用的数据。原始日志与分析脚本在仓库外的 `foray_mcu_archive/2026-11-01_heater_warmup/`。

## 由 `a2cfd16_pi.csv` 辨识的热模型

从占空比 u（‰）到读数，等价于两级一阶滞后串联：被加热区 `dx1/dt = (K·u + Ta − x1)/τ1`，传感器 `dx2/dt = (x1 − x2)/τ2`，
读数是 x2 在寄存器更新时刻的截断采样。前 60 s 拟合（多组初值，按每次寄存器更新一个残差）：

| 参数 | 值 |
|---|---|
| K（稳态增益） | 0.967 ℃/‰ |
| τ1（被加热区） | 15.5 s |
| τ2（传感器滞后） | 0.95 s |
| 残差 RMS | 0.24 ℃ |

用这个模型仿真旧 PI：过冲 6.0 ℃、±0.25 ℃ 稳定 27.3 s、校准条件 48.7 s，与实测吻合。宿主测试 `heater_control` 用同一模型作被控对象。
