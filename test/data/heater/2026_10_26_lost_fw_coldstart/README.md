# 原固件加热器冷启动记录（2026-10-26）

DM-MC02 上运行的原固件（比 `a2cfd16` 更新、源码已丢失）从断电冷却后重新上电，到恒温稳定的完整过程。数据由 SWD 在**不停核、不复位**的情况下读取，没有烧录任何固件。这是重做加热控制（丢失功能 L6）时的验收下限。

## 对原固件加热算法的观察（只作行为参考，不做逆向）

- 状态与 `a2cfd16` 相同：预热（2）→ 恒温调节（3）。但预热阶段的占空比不是固定的 200‰，而是从 67 逐步降到 24；13 s 时、48.9 ℃ 左右转入调节。
- 占空比读数的单位未确认：稳态只有约 9，若单位是 ‰，则不到 1%。板子自身发热可达 42 ℃ 以上，可能是稳态所需加热功率很小的原因。
- 加热器对象前 128 字节（`a2cfd16` 中为 PID）在原固件中是另一套状态：
  - w02–w11 是 10 格环形缓冲区，w26 是 1–8 循环的下标；
  - 缓冲区数值在上电后几秒内升到约 63 ℃（此时传感器才读到 48–49 ℃），之后十几分钟缓慢回落到约 49.4 ℃，像控制器内部估算的热源侧温度；
  - w30 等于最近一次传感器读数；w31 在 0.5–1.28 s 之间变化，与 BMI088 温度 1.28 s 的更新周期吻合，疑似距上次传感器更新的时间；w27、w28 是浮点估计量与修正量。
- 由此推断，原固件用模型估算补偿 BMI088 温度更新慢（`a2cfd16` 注释中约 1.45 s 的反馈盲区），从而做到升温快、过冲小。重做时可以朝这个方向设计，但实现以新结构中的需求和测试为准。
