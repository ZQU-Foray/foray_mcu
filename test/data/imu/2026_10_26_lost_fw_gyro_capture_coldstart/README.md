与 [`2026_10_26_lost_fw_gyro_capture`](../2026_10_26_lost_fw_gyro_capture/README.md) 相同的采集机制、相同的固件，在加热器冷启动记录（[`test/data/heater/2026_10_26_lost_fw_coldstart`](../../heater/2026_10_26_lost_fw_coldstart/README.md)）期间自动完成：温度在 IMU 启动后约 17.8 s 进入 50 ±0.5 ℃，20.7 s 开始采集。用途是验证第一份数据的可重复性。

| 项 | 值 |
