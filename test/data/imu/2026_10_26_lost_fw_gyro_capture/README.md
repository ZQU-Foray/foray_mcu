# 原固件陀螺静态采集（2026-10-26）

DM-MC02 上运行的原固件（比 `a2cfd16` 更新、源码已丢失）在恒温点自动完成的一次陀螺采集。数据由 SWD 在**不停核、不复位**的情况下从 RAM 中读出，没有烧录任何固件。

## 来源

| 项 | 值 |
|---|---|
| 固件 | 芯片原固件，Flash 镜像 SHA-256 `e307e4b762ff78b7d61d9ab8d817f3f0ab4e47de7881f7598a0e6f51d301f43d`（见 `docs/decisions/2026-10-25-迁移基线与对照.md` §8） |
| 结构体 | `ImuDiagnostics` 的 `Capture`，版本 2，16720 字节，定义见 `legacy/Application/Imu/ImuDiagnostics.cpp`；原固件中位于 `0x24000788`（`a2cfd16` Debug 中为 `0x240006b0`） |
| 读取 | 2026-10-26，OpenOCD 0.12.0 + CMSIS-DAP（Vllink Basic2），整块读出 AXI SRAM 后提取；整块快照 SHA-256 `2bcb24744f43ab149db12682e102700933d81e3614f1e4313cfd898f9a564fb5`（保存在仓库外的存档目录） |
| 解码 | `tool/debug/imu_capture_decode.py <AXI 快照> --base 0x24000000 --address 0x24000788 --extract capture.bin --csv samples.csv --json summary.json` |

## 采集条件

- 触发：上电后温度进入 50 ±0.5 ℃ 并保持 3 s，自动开始；统计 20000 个样本后冻结。
- 温度：开始 49.625 ℃，结束 49.875 ℃。
- 传感器配置（按 `a2cfd16` 源码；原固件 Flash 中只找到 ±2000 dps 的换算常量，判断沿用同一配置）：BMI088 陀螺 ±2000 dps（1 LSB = 2000/32768 = 0.0610 dps）、ODR 2000 Hz、滤波带宽 532 Hz。
- 机器人状态（电机是否上电、是否装在车上）：**未记录**。

## 已知问题

- **噪声偏大**：按 ±2000 dps 量程，BMI088 在 532 Hz 带宽下的理论白噪声约 0.3 dps（约 5 LSB），实测大一个数量级。1024 个原始样本的频谱能量集中在 600–1000 Hz（接近奈奎斯特频率），相邻样本自相关约 -0.6，像高频振动或电磁干扰混叠，原因未查明。使用这份数据做零偏或噪声基准时要注意这一点。
- 只保存了 1024 个原始样本（约 0.5 s），其余 18976 个样本只有统计量；没有加速度计原始样本。用于姿态解算回归时数据量不足，需要另行录制（见 `plan.md`）。
- 采集开始时的读取序号为 38543，按约 2000 Hz 推算，采集在陀螺开始工作后约 19 s 开始，即温度在上电后约 16 s 内进入 50 ±0.5 ℃。当时板子是否从冷态启动未知，冷启动加热曲线另见 `test/data/heater/`。
